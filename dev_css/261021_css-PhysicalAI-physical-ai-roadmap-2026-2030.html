제강 → 압연 → 품질 관리

데이터 계보를 먼저 확보하고, AI 개입 수준을 모니터링에서 제한적 자율제어까지 단계적으로 높이는 51개월 추진 계획입니다.

과제 기간 2026.10 ~ 2030.12 총 51개월 범위 EAF·LF·VD → 연주 → 가열로·압연 → 정정·품질 작성일 2026-10-21
1. 추진 원칙 2. 전체 흐름 3. 일정표 4. 업무 연계도 5. 단계별 상세 6. 안전 제어 흐름 7. 실패 예방

1추진 원칙

①데이터 계보 우선
Heat → Billet/Bloom → 압연 Lot/Coil → 품질 시험 결과의 추적 체계를 가장 먼저 확보합니다. 계보가 없으면 공정 간 AI 학습 데이터를 만들 수 없습니다.
②AI 개입 수준의 단계적 상향
모니터링(L0) → 예측(L1) → 권고(L2) → 승인형 제어(L3) → 제한적 자율제어(L4) 순서로 올립니다. 설비 쓰기 권한은 마지막에 부여합니다.
③품질 → 압연 → 제강 순 공략
리스크가 낮고 성과가 빠른 품질부터 시작합니다. 품질 단계에서 만든 라벨이 상위 공정 모델의 정답 데이터가 됩니다.
④안전장치는 제어보다 먼저
입력 검증 게이트, 출력 제한, 기능 차단(Kill switch), 수동 롤백이 갖춰지기 전에는 폐루프 제어를 하지 않습니다.
일정은 달력 연도 기준입니다. 협약상 차년도 구분이 다르면 해당 기준에 맞춰 조정합니다.
