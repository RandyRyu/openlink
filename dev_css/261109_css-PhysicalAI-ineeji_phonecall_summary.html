2. 주요 통화 내용

2.1 예산과 견적

  • VNTG: 받은 문서 기준으로 약 2 M/M 수준을 예상해 정리해 둠 확인 필요
  • 인이지: 올해 예산 5,000만 원으로 잡혀 있음. M/M 기준 견적도 괜찮음.
  • VNTG: 2개월 기준이면 2.5~3 M/M로 정리 제안.
  • 9월 시작으로 잡으면 초반 몇 달을 0.5~1 M/M로 계산해 금액을 맞추는 방식에 공감.

2.2 계약 방식

  • 인이지가 과업 위주로 정리한 과업지시서를 보내고, VNTG가 수행하기로 하면 계약서를 체결.
  • 과업지시서는 인이지 계획서와 같은 골격에, 몰랐던 내용(DataForge 활용 등)을 추가.
  • 인이지 관행: 자사 용역계약서에 업무지시서를 첨부해 계약하고, 산출물·보고서를 받으면 잔금 지급.
  • 데이터 분석까지 범위에 넣을지는 인이지 최찬희 선임과 논의 후 결정 확인 필요

2.3 지급 방식

  • 인이지도 정부로부터 연차별로 예산을 받음. 협약이 끝나 집행 승인이 났음.
  • 용역 기간이 짧아 선금 + 잔금으로 단순하게 진행.
  • 내년에도 이슈가 없으면 연초 계약 → 선금 → 연말 잔금의 동일 방식.
  • 용역이므로 산출물과 보고서가 있어야 지급에 문제가 없음.

2.4 보고 의무

  • 국가과제 공식 중간보고는 기본 1회. 참여기업은 진행 보고 의무가 있으나 용역은 별도 요구 없음.
  • 인이지 과업 보고에 VNTG 진행 상황이 필요할 때는 요청할 수 있음.
  • 인이지는 데이터를 최대한 많이 받아야 해서 수시로 자주 연락할 예정. 타겟만 명확하면 데이터 제공은 큰 문제가 없음.

2.6 실시간 필요 여부와 모델 적용 시점

  • 현재 실시간 요구 없음. 과거 데이터로 모델링하는 단계.
  • 현장 모델 적용은 2차년도(2027) 후반 이후 예상.
  • 전기로 경험은 있으나 같은 모델을 그대로 쓸 수 없어 튜닝 범위 파악이 필요.
  • 데이터 연계성은 DataForge가 잘 갖추고 있어 적극 활용하고 싶다는 입장. ("없었으면 하나하나 같이 만들어야 했다")

2.7 NDA와 데이터 점검 결과 공유

  • 세아창원특수강 NDA는 아직 법률 검토 중. 인이지도 일정에 부담을 느낌.
  • VNTG는 인이지(최찬희 선임)의 데이터 항목 목록에 보유 / 일부 보유 / 확인 필요를 표시한 결과를 세아 스마트팩토리팀에 전달 완료(인이지에 직접 줄 수 없는 구조).
  • 이경은 팀장은 결과를 아직 보지 못함. 최찬희 선임에게 전달됐는지 확인하기로 함.

2.8 계약 기간(소급 여부)

  • 계약이 늦어졌을 뿐 일은 9월(또는 8월)부터 해왔다고 서류상 처리할지, 11월 시작으로 할지 확인 필요.
  • 국가과제는 보통 소급 처리를 원함. 결정은 총괄기관. 이경은 팀장은 "보통 9월부터"로 예상.
  • 결정된 시작 시점에 맞춰 계약 기간을 잡고 VNTG가 견적을 조정.

2.9 참고: 인이지의 VNTG 이노베이션센터 방문

  • 이경은 팀장이 통화 당일 VNTG 이노베이션센터(센터장·매니저)와 미팅. 계약 건이 아니라 이노베이션센터가 준비 중인 자체 서비스의 대외 사업에 대한 의견을 듣는 자리였음.
  • 인이지는 그 자리에서 DataForge를 높이 평가했다고 전함.
  • DataForge팀은 사전에 공유받지 못한 건이라 사내 확인이 필요해 보임.
