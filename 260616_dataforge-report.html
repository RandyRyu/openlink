632KB · 아키텍처 설계 종합 레퍼런스

원칙 1 — 인프라 SSoT

모든 파이프라인 설정의 원본은 DF-Stream DB에 있다. Benthos·Kafka·SR은 DB의 내용을 반영한 결과물. DFSTREAM-336 이후 KEPServer도 동일 원칙 적용.

원칙 2 — 의미론 SSoT

모든 데이터의 정의·명칭 원본은 표준 사전(data_standard)에 있다. 각 엔티티는 standard_term_uid FK로 참조. 2026-06 Instance 이관 완료 → Class(보통명사)만 사전에 남음.

TimescaleDB TSL 정책 (DFSTREAM-540) 신규

-- hypertable 설정 chunk_interval : 6시간 압축 정책 : 2일 경과 후 (chunk 1일) retention 정책 : 30일 후 자동 삭제 -- 연속 집계뷰 mv_tag_rt_5m (CAGG, 5분 평균/최대/최소) schedule_policy: 매 5분 정책 갱신 -- 효과: 894MB → 46MB (압축 95% 절감) PK: asset_id + tag_id + source_ts

자격증명 암호화 체계 (신규)

── AES-256-GCM (복호 가능) ────────────── 대상 : DB/REST source 자격증명 비밀번호 흐름 : 평문 → encrypt() → iv:tag:ciphertext pipeline-generator에서 1회만 decrypt() 응답/로그/예외 메시지에 복호결과 금지 ── SHA-256 (단방향) ────────────────────── 대상 : 파이프라인 ingest API key 형식 : dfsk_{env}_... 저장 : benthos_pipeline_api_key_mt.key_hash 검증 : hashKey(plaintext) === key_hash
