03

시스템 아키텍처 가이드 NEW 2026-04-28

601KB · 아키텍처 설계의 종합 레퍼런스

원칙 1 — 인프라 SSoT

모든 파이프라인 설정의 원본은 DF-Stream DB에 있다. Benthos·Kafka·SR은 DB 내용을 반영한 결과물. 직접 조작 금지. DB → SR → Benthos → KafkaConnect 순 6단계 오케스트레이션 필수.

원칙 2 — 의미론 SSoT

모든 데이터의 정의·명칭 원본은 표준 사전(data_standard)에 있다. 각 엔티티는 standard_term_uid FK로 사전 참조. 사전에 고유명사 직접 등록 금지.

1:1:1:1 정책 — 공장 단위 파이프라인 격리

공장(Factory) 1:1 Stream(Benthos Pipeline) Stream 1:1 Kafka Topic Kafka Topic 1:1 Connector (JDBC Sink) Connector 1:1 DB Table (tag_rt) 예: changwon_srl 공장 공장 : changwon_srl Stream : changwon-srl-kepserver1-01 Topic : css.changwon_srl.tag Connector : css.changwon_srl.tag.sink DB Table : changwon_srl.tag_rt
한 공장 장애가 다른 공장에 영향 없음. 독립 운영·장애 추적·스키마 분리 보장.

DFSTREAM-336 POC — Tag Lifecycle 상태 전이 (4/22 완료)

DRAFT → address 없이 생성 — 관리자가 이후 수동 Activate
PENDING_PUSH → address 있는 생성 요청 — KEP push 대기 중
ACTIVE ↔ KEP push 성공 — retry-push로 복구 가능
PUSH_FAILED → KEP push 실패 — DB 행 유지 + 에러 상세 기록
ORPHANED → KEP에서 삭제됨 — Drift Detection 자동 감지
ownership: LEGACY / DF_STREAM_OWNED / KEP_OWNED / SHARED

Benthos 4 Processors (표준화 확정)

① except_system_nodes _* · ns=0;* · nodeid i=* 필터링
② filter_bad_quality statuscode !contains 'Good' → drop
③ bool_to_int Boolean 값 → INT 변환
④ opcua_schema_registry schema_registry_encode (Avro 직렬화)

표준 사전 — 3계층 구조

① 단어 (Word) 온도, 압력, 모터, 전류, 설정… ↓ 조합 ② 용어 (Term) 온도 / 모터_전류 / 온도_설정값 ↓ 규칙 부여 ③ 도메인 (Domain) 온도_도메인 : FLOAT · ℃ · -50~2000 압력_도메인 : FLOAT · MPa · 0~100 → AI 이상탐지 기준값 자동 도출
