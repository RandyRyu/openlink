// apps/api/src/streams/streams.service.ts
StreamsService.deploy(CreateStreamDto, User)

1. StreamLogsService.createLog(action: 'deploy', status: 'in_progress')
2. DfPackageService.getOpcServerByUid(uid) → opc_server_mt + endpoint_mt
3. DfPackageService.getOpcServerNodes(uid) → opc_server_node_mt
4. DfPackageService.getKafkaClusterByUid(uid) → cluster_mt + broker_mt
5. DfPackageService.getKafkaClusterTopics(uid) → kafka_topic_mt
6. BenthosConfigGeneratorService.generate(params)
├── buildInput() → OPC-UA input (poll/subscribe/broker)
├── buildKafkaOutput() → Kafka output (addresses, topic, compression)
└── buildPipeline() → Bloblang + Schema Registry encode
7. Stream UPSERT (status: 'deploying', deployed_config: json)
8. callBenthosApi(baseUrl, streamId, config) ← POST /streams/:id (30s timeout)
9a. SUCCESS: stream.status = 'active', last_deployed_at = now()
9b. FAILURE: stream.status = 'error', stream.error_message = error

개발 정책 확정

OPC-UA 수집 Class

Class A실시간/라인100ms ~ 500ms
Class B배치/설비1s ~ 5s
Class C집계/운영10s ~ 1min
보안: Basic256Sha256 / Sign & Encrypt
노드: [Site].[Area].[Line].[AssetID]
인증: Service Account Authentication

Kafka 클러스터 정책

KRaft 3 Broker (HA, Split-brain 방지)
Auto Create Disabled — 명시적 토픽 생성만
Retention: 7일 / 50GB (파티션당)
Replication factor: 3 · Min ISR: 2
압축: snappy (기본) / gzip/lz4/zstd 선택
Schema Registry: BACKWARD_TRANSITIVE
Kafka Connect Upsert (PK: asset_id, timestamp)
DLQ: errors.tolerance=all, {topic}.error

보안 정책

JWT: RS256 (apps/auth Private Key 서명 → JWKS 공개)
Access Token: 15분 / Refresh Token: 7일
RBAC: admin > operator > viewer (API 엔드포인트 단위)
로그인 실패 5회 → 계정 잠금 (loginAttempts)
Multi Auth: Local / Google OIDC / LDAP·AD / 외부 OIDC IdP
도메인 화이트리스트: AUTH_ALLOWED_DOMAINS
로그 민감정보 마스킹: password, token, secret, hash, salt

네이밍 컨벤션 (확정)

Kafka Topic css.{bp}-{factory}.{source}-{dataset}
ex) css.changwon-fp.mes-heat-treat-extract-result
Stream ID = Kafka Topic (동일)
Connector {topic}.sink
Consumer Group {topic}.timescale
DLQ Topic {topic}.error
Avro Subject css.{bp}_{factory}.{source}_{dataset}
DB Schema {bp}_{factory} → changwon_fp
DB Table {source}_{dataset}_tt → mes_heat_treat_extract_result_tt
