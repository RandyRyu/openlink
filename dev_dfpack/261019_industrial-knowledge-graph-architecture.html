isa95-neo4j-agent · 샘플 구현 구성

산업 데이터 지식 그래프 구성도

ISA-95 역할 계층을 뼈대로 한 Neo4j 그래프에 OPC UA 태그, AAS 식별자, RAG 문서 포인터를 같은 엔티티 ID로 묶고, AI Agent는 목적형 도구를 통해서만 이 그래프에 접근합니다. 실선은 샘플 코드에 구현된 부분, 점선은 외부 시스템과 이어지는 연동 지점입니다.

01 · 시스템 구성

구성 요소와 데이터 흐름

위에서 아래로 질문이 내려가고 근거가 올라옵니다. 그래프는 가운데에서 모든 계층의 색인 역할을 하고, 실시간 값과 문서 본문, AAS 원본은 그래프 밖에 둡니다.

02 · 온톨로지

노드와 관계: 무엇이 무엇과 어떻게 이어지는가

각 상자의 회색 줄은 실제 속성, 마지막 줄은 샘플 데이터의 인스턴스입니다. 화살표 방향이 관계의 의미이고, 중괄호는 관계에 붙은 속성입니다.

03 · 규격과 개념별 적용

각 계층이 담는 정보와 제공하는 기능

상태 표시: 구현 샘플 코드에서 동작, 일부 핵심만 구현, 연동 지점 외부 시스템이 필요.

04 · 질의 추적

질문 하나가 계층을 지나가는 순서

“공압기 2호기가 멈추면 어디에 영향이 가고, 관련 장애 이력과 문서, 지금 설치된 장비 정보는?”을 샘플 데이터로 처리할 때 도구가 주고받는 값입니다.

#도구계층보내는 값받는 값 (샘플 데이터 기준)
1resolve_entity시멘틱 name="공압기 2호기" WU-GS-UT-COMP02 · 경로 샘플제조(주) › 군산공장 › 유틸리티동 › 압축공기설비 › 공압기 2호기
2get_flowISA-95 위 ID · downstream 압축공기 1홉 → WU-GS-PC1-INJ01 PC1 사출기 1호기
3get_eventsISA-95 · 이력 위 ID EV-2026-0621 전력계 교체, EV-2026-0588 실물 교체, EV-2026-0412 과전류 트립(당시 실물 AS-COMP-A101)
4find_documentsRAG 포인터 위 ID DOC-SOP-COMP, DOC-INC-2026-031, DOC-MAN-SA75V (현재 실물 AS-COMP-B200의 매뉴얼)
5get_aas_referenceAAS 위 ID · 현재 시점 AS-COMP-B200 · globalAssetId https://www.sampleair.example/id/AC-2026-0112 · AAS ID · Nameplate 서브모델 ID
6get_measurement_pointsOPC UA 위 ID · 현재 시점 MP-COMP02-KW → TAG-PM0110-P, MP-COMP02-KWH → TAG-PM0110-E (서버 KEPServerEX-GS01)
7벡터 검색 연동 지점RAG 4번 document_id로 필터 + 질문 임베딩 장애보고서 본문의 원인·조치 문단
8query_metric 연동 지점시멘틱 · 지표 6번 측정 지점 · 기간 TSDB 값. 2026-06-15 이전은 PM0102, 이후는 PM0110 태그로 자동 이어 붙임

1번이 실패하면 나머지는 모두 의미가 없어집니다. 그래서 별칭 관리와 resolve_entity의 ambiguous·not_found 처리가 정확도에 가장 큰 영향을 줍니다. 1~6번은 LLM이 Cypher를 쓰지 않고 파라미터만 고릅니다.
